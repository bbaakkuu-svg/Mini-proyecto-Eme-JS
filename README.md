# Mini-proyecto-Eme-JS
Enunciado Vais a desarrollar una pequeña aplicación web (un motor lógico en un archivo app.js conectado a un index.html) que simule la gestión de alertas de un parque de bomberos/ambulancias. El proyecto se estructurará bajo estándares estrictos de la industria: depuración profesional, documentación normalizada y despliegue continuo.
